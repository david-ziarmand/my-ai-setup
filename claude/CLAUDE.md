# Global

The user is a web developer who builds client sites: landings, multi-page sites, and online stores, on WordPress or Next.js + Payload. Works in JetBrains IDEs.

- Rules live in `~/.claude/rules/` and load automatically: some always, stack rules by `paths`.
- Skills live in `~/.claude/skills/`.
- Project knowledge lives in the project's `AGENTS.md`, `docs/`, and `plans/`. If a project has no `AGENTS.md`, suggest the `init-project` skill.
- Source of these files: `https://github.com/davyd-ziarmand/my-ai-setup`. Change them there, not in `~/.claude/` directly.
